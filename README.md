## What is Clean My Windows?

A free, professional-grade Windows optimization app powered by **WinBoost** — a suite of 12 tools that clean junk files, detect malware, manage startups, shred sensitive data, fix registry issues, and tune your system for peak performance.

Built with AI assistance as an experiment in what modern development tooling can achieve.

## Quick Start

```bash
# Download the latest release
# https://github.com/malick186/Clean-My-Windows/releases

# Or build from source
git clone https://github.com/malick186/Clean-My-Windows.git
cd Clean-My-Windows/winboost
npm install
npm run electron:dev
```

## 12 Built-in Tools

| # | Tool | What it does |
|---|---|---|
| 1 | **Dashboard** | System health overview with animated scan ring |
| 2 | **System Cleanup** | Remove junk, caches, temp files, logs |
| 3 | **Malware Scanner** | Quick/full/deep scan with threat quarantine |
| 4 | **App Uninstaller** | Complete removal with leftover detection |
| 5 | **File Shredder** | Secure delete with DoD & Gutmann methods |
| 6 | **Maintenance** | 12 system scripts: DNS flush, SFC, DISM, CHKDSK |
| 7 | **Disk Analyzer** | Visual storage breakdown with charts |
| 8 | **Large Files** | Find space-hogging files |
| 9 | **Registry Cleaner** | Fix broken entries & orphaned keys |
| 10 | **Startup Manager** | Control boot programs & boot time |
| 11 | **Privacy Tools** | Manage telemetry, location, camera settings |
| 12 | **Performance** | 12 system tweaks with benchmarks |
